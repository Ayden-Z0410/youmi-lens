Improves long lecture recording reliability, local recording persistence, pending-upload recovery, and adds in-app update support for future releases.

### Highlights
- Improved long lecture recording stability
- Incremental local recording persistence during capture
- Reduced expected recording size using speech-oriented Opus settings (64 kbps)
- Improved pending-upload durability and retry
- In-app update support for future releases

### Notes
- This is a bridge release: install once to enable future in-app updates.
- Automated pending-upload tests cover retry durability; manual offline network testing was waived for this release.
